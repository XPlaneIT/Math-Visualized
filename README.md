# Math Visualized

This repository contains Python/Manim animations visualizing various mathematical concepts. 

## 📂 Repository Structure
*   `_011quadratic_portrait.py`: Visualizing quadratic equations (Portrait format).
*   `_012inverse_portrait.py`: Visualizing inverse functions (Portrait format).


## ⚙️ How to Run
To render these scenes, use the following command:
```bash
uv run python -m manim -pqh -r 1080,1920 <filename.py> <SceneName>
